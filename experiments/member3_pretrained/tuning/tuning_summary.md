# 调参汇总（20k 子集，seed 42，6 轮预算）

基准：GloVe 微调 BiLSTM，lr=0.001，batch=64，dropout=0.3，hidden=128，max_len=128。
每次只改一个参数，验证 Macro-F1：

| 参数 | 试过的值 | 验证 Macro-F1 |
|---|---|---|
| 学习率 | 0.0005 / 0.001 / 0.002 | 88.59% / 88.87% / **89.12%** |
| batch size | 32 / 64 / 128 | **89.30%** / 88.87% / 88.95% |
| dropout | 0.2 / 0.3 / 0.5 | 88.20% / **88.87%** / 88.67% |
| 隐藏单元 | 64 / 128 / 256 | 88.47% / 88.87% / **89.10%** |

选出的最佳组合：lr=0.002，batch=32，dropout=0.3，hidden=256。
该组合正式训练（10 轮）的验证 Macro-F1 = **89.75%**（最佳轮次 2）。

权衡：hidden=256 比 128 只高约 0.2 个点，但每轮耗时约 2 倍；128 是性价比更高的选择。
