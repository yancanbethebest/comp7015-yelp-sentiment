# 报告 Experiments 部分 —— 预训练词向量与超参数调优

> **作者**：成员三
> **版本**：v3.0（2026-11-12，补充全量数据结果）
> **数据**：成员一 fixed splits；20k 子集（train 20,000 / val 4,000，seed 42）与全量（train 503,979 / val 55,998）
> **测试集**：未评估，留到成员五统一最终评估

## 1. 实验目标

1. 在固定数据划分上，GloVe 预训练词向量是否优于随机初始化词向量？
2. 预训练词向量应该冻结还是微调？
3. 学习率、batch size、dropout、隐藏单元数如何影响性能？

公平对比的硬约束：同一份数据、同一份词表、同样的 BiLSTM 结构和训练预算，唯一变量是 embedding 初始化来源（以及是否冻结）。

## 2. 实验设置

| 项目 | 20k 子集（调参/分析） | 全量（最终） |
|---|---|---|
| 数据 | train 20,000 / val 4,000 | train 503,979 / val 55,998 |
| 文本表示 | 词表 30,000，max_len=128 | 词表 30,000，max_len=256 |
| 模型 | BiLSTM，embedding_dim=100 | 同左 |
| 训练 | AdamW，早停 | AdamW，50 轮预算 + 早停 |
| 硬件 | 本机 CPU | Kaggle GPU T4 |
| 词向量 | GloVe 6B-100d（覆盖训练词表 83.57%） | 同左 |

## 3. 20k 子集核心对比

| 模型 | 最佳轮次 | 验证 Accuracy | 验证 Macro-F1 | 可训练参数量 |
|---|---:|---:|---:|---:|
| 随机词向量 | 3 | 87.58% | 87.56% | 3,236,034 |
| GloVe 冻结（10 轮） | 10 | 88.10% | 88.09% | 236,034 |
| GloVe 微调（默认参数） | 3 | 88.88% | 88.87% | 3,236,034 |

结论：预训练词向量有帮助（约 1.3 个百分点）；冻结收敛更慢。

## 4. 20k 超参数调优

一次只改一个参数，基准为 GloVe 微调，6 轮预算。

| 参数 | 试过的值 | 验证 Macro-F1 |
|---|---|---|
| 学习率 | 0.0005 / 0.001 / 0.002 | 88.59% / 88.87% / 89.12% |
| batch size | 32 / 64 / 128 | 89.30% / 88.87% / 88.95% |
| dropout | 0.2 / 0.3 / 0.5 | 88.20% / 88.87% / 88.67% |
| 隐藏单元 | 64 / 128 / 256 | 88.47% / 88.87% / 89.10% |

微调最佳组合（lr=0.002，batch=32，dropout=0.3，hidden=256）= 89.75%，但过拟合最重。

## 5. 20k 过拟合分析

微调版训练准确率第 5 轮即达 99% 以上，验证停在 89% 附近，过拟合明显。尝试正则化（89.17%，略缓解）与冻结（可训练参数降到 236,034，过拟合最轻）。20k 上采用冻结（20 轮）得 89.00%。

## 6. 全量数据实验（最终结果，GPU T4）

| 模型 | 最佳轮次 | 验证 Accuracy | 验证 Macro-F1 |
|---|---:|---:|---:|
| GloVe 冻结 | 7 | 95.62% | 95.62% |
| GloVe 微调（默认参数） | 2 | 95.77% | 95.77% |
| GloVe 微调（调参最佳组合） | 2 | 95.73% | 95.73% |

参考：成员二随机基线（全量）BiLSTM 95.33% / BiGRU 95.65%。

结论：

1. 全量上预训练词向量仍略优于随机，但优势明显缩小：20k 约 1.3 个百分点，全量约 0.1–0.4 个百分点。数据量越大，预训练词向量的额外收益越小。
2. 默认微调（95.77%）最高，略高于冻结（95.62%）和调参组合（95.73%）。20k 上调出的最优组合在全量上没有带来额外提升，说明该任务在充分数据下对超参数不敏感。
3. 冻结版参数量最少（236,034），分数几乎持平，是性价比最高的选择。

## 7. 计算成本

| 配置 | 参数量 | 每轮耗时 |
|---|---:|---:|
| 冻结 hidden=128 | 236,034（可训练） | CPU 约 110–250 s；T4 约 200 s |
| 微调 hidden=128 | 3,236,034 | CPU 约 140 s；T4 约 210 s |
| 微调 hidden=256 | 3,734,210 | CPU 约 300 s；T4 约 400 s |

## 8. 局限

1. 单种子（seed 42），未做多种子方差分析。
2. 20k 与全量的 max_len 不同（128 vs 256），口径需分开说明。
3. max_len 会截断长评论。
4. GloVe 覆盖词表 83.57%，约 16% 的词仍为随机初始化。
