# 报告 Experiments 部分 —— 预训练词向量与超参数调优

> **作者**：成员三
> **版本**：v2.0（2026-11-06，冻结版定为最终方案）
> **数据版本**：成员一 fixed splits，分层抽取 train 20,000 / val 4,000（seed 42）
> **测试集**：未评估，留到成员五统一最终评估

## 1. 实验目标

本部分回答三个问题：

1. 在固定数据划分上，GloVe 预训练词向量是否优于随机初始化词向量？
2. 预训练词向量应该冻结还是微调？
3. 学习率、batch size、dropout、隐藏单元数如何影响性能？

公平对比的硬约束：同一份数据、同一份词表、同样的 BiLSTM 结构和训练预算，唯一变量是 embedding 初始化来源（以及是否冻结）。

## 2. 实验设置

| 项目 | 设置 |
|---|---|
| 数据 | processed_data，train 20,000 / val 4,000（分层抽样，seed 42） |
| 文本表示 | 小写化 + 正则分词，词表 30,000（仅训练集拟合），max_len=128 |
| 模型 | BiLSTM，embedding_dim=100，hidden=128，dropout 0.3 / 0.1 |
| 优化 | AdamW，lr=1e-3，weight_decay=0.01，batch=64，grad_clip=1.0 |
| 训练 | 20 轮预算（冻结版），早停，选模指标 = 验证 Macro-F1 |
| 种子 | 42（单种子；CPU 限制，多种子留作后续） |
| 词向量 | GloVe 6B-100d（400,000 词，覆盖训练词表 83.57%） |

## 3. 核心对比

| 模型 | 最佳轮次 | 验证 Accuracy | 验证 Macro-F1 | 可训练参数量 |
|---|---:|---:|---:|---:|
| 随机词向量 | 3 | 87.58% | 87.56% | 3,236,034 |
| GloVe 冻结（10 轮） | 10 | 88.10% | 88.09% | 236,034 |
| GloVe 微调（默认参数） | 3 | 88.88% | 88.87% | 3,236,034 |

结论：

1. 预训练词向量有帮助：GloVe 微调比随机高约 1.3 个百分点。
2. 冻结收敛更慢：冻结在 10 轮后仍在提升，而微调在第 3 轮已见顶。

## 4. 超参数调优

采用一次只改一个参数的单变量对照，基准为 GloVe 微调（lr=0.001，batch=64，dropout=0.3，hidden=128），6 轮预算。

| 参数 | 试过的值 | 验证 Macro-F1 |
|---|---|---|
| 学习率 | 0.0005 / 0.001 / 0.002 | 88.59% / 88.87% / 89.12% |
| batch size | 32 / 64 / 128 | 89.30% / 88.87% / 88.95% |
| dropout | 0.2 / 0.3 / 0.5 | 88.20% / 88.87% / 88.67% |
| 隐藏单元 | 64 / 128 / 256 | 88.47% / 88.87% / 89.10% |

微调最佳组合（lr=0.002，batch=32，dropout=0.3，hidden=256）的验证 Macro-F1 = 89.75%，但过拟合最重。

## 5. 过拟合分析与最终方案

微调版训练准确率第 5 轮即达 99% 以上，而验证分数停滞在 89% 附近，过拟合明显。尝试了：

- 正则化（weight_decay=0.05 + embedding_dropout=0.3）：89.17%，略有缓解。
- 冻结 GloVe：可训练参数从 3,236,034 降到 236,034，背答案速度明显变慢。

**最终采用 GloVe 冻结（20 轮预算 + 早停）**：

- 验证 Accuracy **89.00%**，Macro-F1 **89.00%**，最佳轮次 11。
- 该方案分数与微调接近，但过拟合明显更轻，泛化更稳。

## 6. 计算成本

| 配置 | 参数量 | 每轮耗时（CPU） |
|---|---:|---:|
| GloVe 冻结 hidden=128 | 236,034（可训练） | 约 110–250 s |
| GloVe 微调 hidden=128 | 3,236,034 | 约 140 s |
| GloVe 微调 hidden=256 | 3,734,210 | 约 300 s |

> 本模块在 CPU 上完成，耗时只反映本机环境。

## 7. 局限

1. 单种子（seed 42）结果，未做多种子方差分析。
2. 数据为 20k 子集，不能与成员二全量结果直接比较。
3. max_len=128 会截断长评论。
4. GloVe 覆盖词表 83.57%，约 16% 的词仍为随机初始化。
